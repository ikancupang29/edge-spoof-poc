Batch Tes Deterministik — 5 kelas, hasil ≤1 menit per tes

Semua kelas ini punya preseden issue Chromium (P1/P2) tapi statusnya di Edge 154 belum tentu keburu — makanya harus DITES, bukan ditebak. Tes 1-3 & 5 cross-origin dari github.io. Rekam video per tes. Prediksi jujur: 1 & 4 paling layak dicoba dulu.
1. Screen Share Picker vs Nav Race — P1 #420734141
Klik → picker "Choose what to share" muncul → JANGAN diapa-apain → 400ms kemudian tab navigasi ke httpbingo (loading 8 dtk). Amati: picker tetap terbuka saat bar pindah? Tulisan origin di picker ("…with ikancupang29.github.io") berubah jadi httpbingo.org?
HIT: picker masih buka lintas origin DAN/OR label origin picker salah (nyebut target padahal yang minta github.io). BUKAN BUG: picker nutup duluan.
2. Filename download sembunyiin ekstensi — P2 #467442136 + #41487774
3 file di-download dengan nama buatan → zoom bubble/shelf download, baca nama yang tampil vs nama asli:
• RLO: nama asli …gnp.exe, kalau RLO ke-render harusnya tampil …exe.png
• Blank U+2800: 60 spasi braille sebelum .exe — apakah .exe kesorot keliatan?
• Panjang: 150 huruf + .exe — apakah pemotongan nyembunyiin ekstensi?
HIT: yang tampil di bubble menutupi/menjungkirbalik ekstensi asli .exe. BUKAN BUG: nama asli tetap kebaca semua / karakter aneh di-strip (itu fix).
3. Download → redirect: origin bubble salah — P1 #40095527
File di-download dari github.io → 300ms kemudian tab redirect ke example.com. Amati bubble download: nyebut github.io (bener) atau example.com (origin nyasar)?
HIT: bubble/shelf nulis origin example.com padahal file datang dari github.io. BUKAN BUG: tetap github.io.
4. PiP nutupin notifikasi fullscreen — P1 #40063918
Klik → fullscreen → 600ms kemudian jendela PiP kecil terbuka. Amati: teks "Press Esc to exit fullscreen" masih keliatan atau ketutup PiP?
HIT: notifikasi exit-fullscreen hilang/ketutup PiP (user gak tau lagi fullscreen). BUKAN BUG: notif tetap keliatan. (Esc = keluar fullscreen)
5. tel: bubble hijack address bar — P2 #41492087
Klik link tel: → handler telepon muncul → amati address bar/bubble di atasnya: domain yang tampil tetep github.io atau berubah jadi nama kontak/tujuan?
HIT: address bar/bubble nampilkan identitas selain origin halaman.
